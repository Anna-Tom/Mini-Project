# Mini-Project

# Global Freelancers Dataset

## Project Overview
An interactive Global Freelancers Dashboard developed using Microsoft Excel and Power BI to analyze how geographic location, experience and hourly rates influence customer satisfaction.
## Aim
To clean and standardize a messy  global freelancer dataset in order to analyze how geographic location, experience, and hourly rates influence customer satisfaction scores.
## Project Phases
Phase 1 - Excel
* Data cleaning and transformation
* Handling missing values
* Standardizing Formats
* Removing inconsistencies
* Creating pivot tables

Phase 2 - Power BI
* Multiple visualizations that communicate insights clearly
* Appropriate use of charts
* Clear and interactive layout
* Proper titles, labels and legends
## Dashboard Pages
* Executive Summary
* Talent Profile
* Demographics and Quality Insights
* Insights and Recommendations
* Freelancer Profle Details 
## Key Metrics
* Total Number of Freelancers
* Average Hourly Rate
* Average Rating
* Average Client Satisfaction
* Active Talent Pool
## Outcome
Designed a high performance report tracking a global freelancers marketplace dataset using Power BI and Excel.
